# Como instalar a skill shopify-dev

Copie esta pasta inteira (com `SKILL.md` e `references/`) para o lugar da sua ferramenta:

- Claude Code: `~/.claude/skills/shopify-dev/`
- Codex: `~/.agents/skills/shopify-dev/` ou `~/.codex/skills/shopify-dev/`

Exemplo para o Claude Code, a partir da pasta do pacote:

```
mkdir -p ~/.claude/skills && cp -R skill-shopify-dev ~/.claude/skills/shopify-dev
```

Depois abra uma sessão nova para a skill ser reconhecida. Esta cópia não leva a documentação local da Shopify: consulte sempre https://shopify.dev/docs.
