# Ofirelle: loja nova

## [⬇️ Baixar tudo (.zip, 9 MB)](https://github.com/mendesadss/entrega-ofirelle/releases/latest/download/Ofirelle-pacote-completo.zip)

Não precisa de conta no GitHub.

## Como aplicar na sua loja

Abra o Claude Code ou o Codex numa pasta vazia e cole esta frase:

```text
Baixe https://github.com/mendesadss/entrega-ofirelle/releases/latest/download/Ofirelle-pacote-completo.zip, descompacte aqui, entre na pasta Ofirelle-pacote-completo, leia o arquivo INSTRUCOES-PARA-O-AGENTE.md e execute.
```

O agente monta tudo numa cópia do tema. A loja no ar não muda até você conferir a prévia e publicar.

Antes de começar, tenha o Shopify CLI instalado e acesso à loja com permissão de temas. A lista completa está em [LEIA-PRIMEIRO.md](LEIA-PRIMEIRO.md).
